In this location, you will find the following files:

1. decipherCustomerSentiment.py - Python based file which can consume customer feedback information available in the form of JSON file and decipher customer sentiments using LLM model (MISTRAL)
2. feedback_data.json - Sample customer feedback data in JSON format.
3. correlation_results - Sample output of the file that can be fed into your Demand planning engine (assuming it can take in correlations for enhancing your demand quality)
4. LLM Result - Screenshot of sample results shown after running the LLM agent.
