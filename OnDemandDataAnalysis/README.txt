This solution space contains the following files:

1. retaildata.zip - Sample retail data from Kaggle. Source is called out below.
2. retail_metadata.csv - Metadata about the source
3. retailPrompt.txt - Context and Prompt inputs to the LLM Agent
4. ollama_agent.py - LLM Agent that generates the ad-hoc data analysis dashboard in streamlit.
5. RAStreamlitApp.py - Actual Streamlit application that you can leverage!

Data source (Kaggle)
https://www.kaggle.com/datasets/ranjithpanicker/ikea-global-product-catalog-and-price-2026
